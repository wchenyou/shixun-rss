# 正式雲端版本的局部延伸

THESIS：讓使用者只保留自己選定的追蹤，並看懂後續資料變化與整理投入。
OWN-WORLD：沿用 repo 447b3a2 的冷暖紙色、墨綠導覽、Noto Serif TC 標題與 Noto Sans TC 正文；不套用另一份 Python 本機版的海軍藍系統。
STORY：閱讀來源 → 選字／主題 → 確認觀察問題 → 查看變化、來源及近七日統計。收藏作為稍後閱讀書籤。用量設定顯示主機尚未套用的真實狀態。
FIRST VIEWPORT：延續追蹤的手動入口、空狀態、狀態篩選及回收區；設定頁先呈現預算與執行端相容性。
FORM：既有設定區段、原生對話框、統計定義列表與資料表，手機單欄與既有導覽。沒有新視覺世界、圖像資產或 approved comp。

檢查桌面 1440×1000、手機 390×844；選字建立、刪除／復原、清空、收藏說明、預算可保存；清除測試項目後，正常列表應保持零追蹤。
